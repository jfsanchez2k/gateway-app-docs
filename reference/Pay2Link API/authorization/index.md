To consume any method of the Pay2Link API it is necessary to send an authentication header.  The authentication header includes a generated token.

To generate a token use the **/Authorize** endpoint and send the generated data as authorization to be consumed.

Each endpoint call must send the following elements in each call

CompanyKey: Value generated by Pay2Link when registering a new company, this is a unique value

Authorization: .Each of the methods must generate a token with the "Authorize" method and send the generated data as authorization to be consumed

This is the method that allows us to generate a token to be able to consume the other methods of the API, to be able to generate a token we only have to supply a valid companyKey.

<br />

| Field      | Type   | Description                                                |
| ---------- | ------ | ---------------------------------------------------------- |
| companyKey | String | Alphanumeric value that identifies a company in the system |

# Payment Cart Detail Specification

The payment cart detail is described below.

| **Component**                            | **Description**                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| `<?xml version="1.0" encoding="UTF-8"?>` | Constant - Start of XML                                                        |
| `<Detail>`                               | Constant - Start of cart detail                                                |
| `<Payment`                               | Constant - Payment record header                                               |
| `MerchantKey="__________"`               | Trade identifier (generated by WebPay)                                         |
| `Service="_________"`                    | Unique identifier of the service or contract / order / invoice (for reference) |
| `MerchantName="__________"`              | Company description (to be presented in the summary)                           |
| `Description="______________"`           | Payment description (to be presented in the summary to the user)               |
| `Amount="________"`                      | Amount of authorization of funds                                               |
| `Tax="0"`                                | Tax amount (reference) \[will be used by default `0`]                          |
| `Currency="840">`                        | Currency of the transaction (based on ISO 4217) \[1]. `840 = US Dollars`       |
| `</Payment>`                             | Constant - End of payment record                                               |
| `</Detail>`                              | Constant - End of cart detail                                                  |

\[1] Currency codes: ISO 4217

## Examples

### JSON

```json
{
  "Payments": [
    {
      "MerchantKey": "TEST-001",
      "Service": "TBW9CVl7",
      "MerchantName": "Amazing Merchant",
      "Description": "test",
      "Amount": 100,
      "Tax": 0,
      "Currency": "214"
    }
  ]
}
```

### XML

```XML
<?xml version="1.0" encoding="UTF-8"?>
<Detail>
  <Payment
    MerchantKey="TEST-001"
    Service="202399292"
    MerchantName="Amazing Merchant"
    Description="Order 123456"
    Amount="1340.50"
    Tax="0"
    Currency="840">
  </Payment>
</Detail>
```

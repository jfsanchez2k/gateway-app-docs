OAuth 2.0 is an industry standard protocol for authorization. It is designed to accommodate a wide range of applications such as web, desktop, and mobile apps by applying specific authorization processes, according to specification.

This web module implements the Client Credentials Grant type adding JWT for content validation.

In OAuth2, a client is an application that can request a token from an identity provider. As the name implies, the client credentials grant type is used to request a token under the context of a client, not a user.

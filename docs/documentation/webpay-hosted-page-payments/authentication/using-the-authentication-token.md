## &#x20;

To authenticate using the token, send the token in the HTTP headers to the requesting page or send the token using a `POST` form field.

### Sample

#### GET /Payment

**Host:** `Webpay URL`

**Authorization:** `Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiIsIng1dCI6Ik5HVEZ2ZEstZnlQ...`

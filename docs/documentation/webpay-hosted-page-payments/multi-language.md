# Language Configuration

You can change the language of WebPay by sending the ISO culture code in the `culture` variable the iso initials of the desired language.

![](https://files.readme.io/b7357bb7300a3cbf6fdc7cb315dd647683e085fce491c2b5f8199e2d3cd305e0-6b18509d8660a2e816176bdeb1cdf86cf44d84efc090c0120103ebf1659f1d95-image.png)

Agilpay has the option of sending automatic reports for transactions made with your merchant credentials.<br />These files can be sent in CSV and Excel format to the addresses that are specified.

Below is the list of predefined files with their formats

- Daily Transactions
- Refunded Transactions
- Return ACH transactions

This automatic reports, can be sent automatically using:

- Email
- Agilpay SFTP folder
- Merchant SFTP folder

<br />

Please request this functionality from your sales agent for automatic scheduling and delivery

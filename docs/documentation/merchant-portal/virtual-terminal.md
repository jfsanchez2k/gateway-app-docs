To make a manual payment, we have to fill out the following information:

Customer Information:
Service: Service name to be paid.

Channel: Channel name to be paid.

Invoice Number: Invoice number Transaction.

Customer Number: Customer identification number (if the customer has previous transactions processed in the system, typing the customer number and pressing the search icon at the right of the field will fill out the customer information and display the saved payment methods in the customer wallet)

First Name: Customer first name

Last Name: Customer Last name

Phone Number: Customer phone number

Email Address: Customer email address·

Address: Customer mailing address

Payment Amount: Amount to be paid.

The information of the payment method varies depending on the payment method selected

![](https://files.readme.io/e30575b8d06c492dfdefd755554734a1e9f6077960d08bd2da78d9e2e5eae322-cdaa1eec0818df8cb66243df4481775c94c860b7d2421611e2b2122a6aef55c7-image.png)

<br />

New ACH:

Bank: Issuer bank of the account.

Routing Number: Bank identification number.

Account Number: Account number to be charged.

Account Type: Account type, there is two options: savings and checking.

Zip Code: Zip area code

Name of Account: Account holder name.

Credit Card:

Credit Card Number: Credit card number to be charged

Expiration Date: Card expiration date

ZIP Code: Zip area code

CVV: Card Security Code

Name of Card: Cardholder name.

If we need to clear all the fields to start over, we press the button 'Clear Form'

If we need make a debit Transaction to the customer account , we press the button 'Sales Transaction'

If we need make a Credit Transaction to the customer account , we press the button 'Refund Transaction'

If we need to view Customer Payment History, we press the button 'Payment History'

if we want to save your credit card or ACH account information click on the option ‘Save to Wallet’.

All the fields shown as mandatory with the red asterisk * must be filled out. After filling out the fields, the 'Submit Payment' button will be enabled and when pressing it, it is shown a preview of the manual payment.

![](https://files.readme.io/7ee79456d406aea823c1e9f67fa5c5091d8cb60290b12c719b8e8476be487a18-a9a9f2a9cd5da6bd9345002165874da73ae010d1e499fd9ba908b4492695b7d8-image.png)

We press the ‘Submit’ button and the transaction will be processed, after that we get a payment confirmation message.

![](https://files.readme.io/dde208e1ef4f3292e1dd6fbceb6a352fb1b0b1e40d733c51ac316b7c398d6901-6a10835283405d8d95fdd426bc3c3e7025ba8756b6a9b431ec49b3dfc14cc4cd-image.png)

In this option, we can create clients once we log in; a modal window with a form will appear.

![](https://files.readme.io/18b738914f2e3a33f35aa6f7e51f1c1fadff4668df6ec05e6b7f82a32356eb20-7b5433695165aa27acd0fe7075e4d85cf3aa61d4337e97aee78773586c49f2a2-image.png)

You must complete the following information:

<br />

Customer Account: Customer code.

Client Name: Full name of the client.

Telephone number: Customer's telephone number.

Email: Customer email.

City: Client's city.

Status: Client status.

Postal code: Postal code.

By filling in the fields by pressing the Save button, the customer record will be generated.

This screen allows the user to update their password to access the system securely.

![](https://files.readme.io/65966992887eeb65275da07e7b9f4ef989f4396d9170a19a0643e660b2d87e7e-98ac23160b330589a90a2ff158c12a819bb836b4c368736001766aff944aa203-image.png)

<br />

Available fields:
Old Password : Field to enter the user's current password.

New Password : Field to define the new password you want to use.

Repeat password : Field to confirm the new password entered.

Available actions:
Update : Saves the changes made and updates the user's password.

Cancel : Discards changes and returns to the previous screen.

✅ Important notes :

The new password must comply with the system's security policies (minimum length, special characters, etc.).

It is recommended to change your password periodically for greater security.

This section allows you to manage the system's test lists. From here, you can view, edit, or configure client profiles.

In this option we can search for Clients and filter by the different search fields:

Account Number: Customer account number.

Name: Customer number.

Status: Customer status.

Once you have selected the filters you want to search for, click the 'Search' button to filter and then view the results:

![](https://files.readme.io/2dcaa73e92019428cfae680b509ca50cabcb08f711559f6f437c2641c14ba7a9-2532f7e09a038d93b4a9074f4e65944ec4bb404db8c87b8d8dcc4b21fb267a8e-image.png)

<br />

Account number : Customer account number.

Name: Client name.

Email: Customer email address.

Telephone: Customer's telephone number.

Status: Client status.

Options: Actions that can be performed on the client, these actions depend on the client's state:

View : Allows you to view customer details.

Edit : Allows you to edit the client.

Disable : Allows you to disable the client.

🛠️ Available actions:

Add Client : Allows you to open a page to create a new Client.

Export to Excel: Allows you to export the customer list in Excel format.

This section allows you to manage system user accounts. From here, you can view, edit, or configure user profiles.

The table shows all users registered in the system with the following information:

![](https://files.readme.io/bd09bc3959e8726af92da1fdcd84bafb1c30e8311230dea29d333df09d417364-ea6ac48ee829dccb81db93f5eb498408d291ed88b4821c1d9895273629f1aa7d-image.png)

<br />

🛠️ Available actions:

➕ New User: Allows you to open a page to create a new user.

✏️ Edit: Modify the selected user's information (email, name, roles, services, etc.).

🔑 Reset Password: Allows you to generate a new temporary password for the user.

🗑️ Delete: Deactivates or deletes the user account from the system.

✅ Notes:

Only users with the Administrator role can perform these actions.

Before deleting a user, the system requests confirmation to avoid errors.

Available fields:
Email Address : Email address associated with the user.

User Name : Full name of the user.

phone : Contact telephone number.

Status : Account status (Active/Inactive).

Profile : Roles assigned to the user to define their access level.

Payment Channel : Channels enabled for the user.

Services : Services enabled for the user.

Change The Password At The Next Login : Option to force a password change at the next login.

Available actions:
Save : Stores changes made to the user's account.

Return to list : Returns to the list of all registered users.

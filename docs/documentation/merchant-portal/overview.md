a)     Web interface: The System is designed based on an interface that works through a web browser, so it can be used from anywhere in the city, the country or the world, without performing a new installation (it will depend on whether it is allowed by the Department of Networks and Security)

b)     Automatic log off: if you leave your PC logged in on the System for a certain amount of time, the System will automatically log off and ask you to re-enter your username and password (generally 20 minutes, it can be defined by Networks and Security).

c)     Context-dependent Security: The application's security system has been designed in the “Content Sensitive” mode, which means that the buttons and menu options may be on or off depending on the profile of the user who is logged in.

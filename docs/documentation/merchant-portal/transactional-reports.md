In this option we can view and print transactional reports.

![](https://files.readme.io/04796ac775d0fcbf6fd1e83f5df6f100fdb0b7f45ef197eb10e9e88c2524bdf1-ba87d9767c6fd70b74e81d8380f20f0c85a13d4c1cb9d3823397070d50c74ab7-image.png)

<br />

We can filter by the different search fields:

Date Type: Transaction date type, there two options: create date and settlement date.

Date From: start of date range.

Date To: end of date range.

Transaction Type: Type Transaction (Sale, Refund and AUTH)

Payment Type: product type used in the transaction (ACH or Credit card - the last four digits).

Status: Transaction status.

ID Transaction: Transaction Identification number.

Customer Number: Customer identification number.

Authorization Number: Transaction authorization number.

CreditCard/Bank Account #: product number used in the transaction (Account number or credit card number).

Amount From: start of amount range.

Amount To: end of amount range.

User: user who submitted the transaction.

Channel: Channel used in the transaction.

Service: Service name that was paid.

Once we have selected the filters we want to search for, we select the report we want to print and press the button 'View Report’ to generate the report.

Note: All reports show the numbers of records and the total sum. The transactional reports are the following:

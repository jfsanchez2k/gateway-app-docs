This document contains in detail a sequence of functions and pages of the Customer Service starting with a summary of the module in an introductory way and a description of its functions.

This guide details all the functionality offered by the solution for all customer service and attention channels, to allow the processing of payments.

The format that follows this manual is about the navigation of the user. It tries to follow a sequential order in the options, pages, and functions that the user uses, presenting and explaining each menu option and each page of the system in detail.

It is important to consider that this manual assumes the user knows the commonly used office tools and knows the basics of Internet / Intranet navigation, so it does not include any information about how to operate a web browser or operating systems the workstations.

If you need information about how to access your computer and how to access the system, you should contact your company's support and / or security department.

In this option we can view and print user reports.

![](https://files.readme.io/383c82761a0d516a13a94096eeece32678bfa6366e61b497897a5b21f6cdde1b-d499442be0a95556c6104ba72f90afdc67c7875461df883dd8948d2df50731aa-image.png)

<br />

We can filter by the different search fields:

Date From: start of date range.

Date To: end of date range.

User Group: group of the user who submitted the transaction.

User: username.

Channel: Channel used in the transaction.

Service: Service name that was paid.

Once we have selected the filters we want to search for, we select the report we want to print and press the button 'View Report’ to generate the report.

The user reports are the following:

User List

This report shows a list of the users and his profiles:

![](https://files.readme.io/6503bccfb9676da3ed9c9e860dd8e480276c673a66b1e1e57855db7876ed1b33-7c5e19970fd06201c9685db271f927ee0b853a4c9d1167491e4c646202496301-image.png)

<br />

User group: group of the user who submitted the transaction.

Service: Channel assigned to the user.

Name: User name.

Security Level: Profile assigned to the user.

Last modified by: User Update date.

Last login Date: Last login date.

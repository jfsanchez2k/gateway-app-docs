In this option we can see the list of batches and filter by their status and the acquirer/host, in addition to this we can access the detail of each batch and execute the manual settlements by acquirer/host.

![](https://files.readme.io/0b24a26b7d1ed1aa7d8db74a9ee48ad97f71a3f3b0a9fa72192c0f57e3218323-4968ace3d733e2615138c0422e71e77f3a0dfb7cc58dbec29e78f6354dcab51f-image.png)

<br />

We can filter by the different search fields:

Merchant: it will allow you to select one of the affiliates available in the system. (they refer to the merchant's affiliate)

Status: Allows you to filter the data by status Open, Closed and Discarded.

Settlement Number: permite digitar el número de cierre de las transacciones.

Date from: le permitirá especificar un rango de fecha para la consulta, en este campo se establecerá la fecha inicial seleccionada para la consulta.

Date to: se podrá especificar un rango de fecha para la consulta, en este campo se establecerá la fecha final del rango.

Date Type: Filter the information by the date the batch was created and the date the batch close was executed.

Process Settlement: allows you to execute the settlement process for the transactions carried out so far and that have already been marked for liquidation.Also included in this closing process closings that are marked for non-automatic execution.

![](https://files.readme.io/83ffe7d0996e25946d3dcd47a27815a7de662c7ddea51e16a9de1061c4c0a77b-7b49d01456e78a36de7ee40f63a0f65427aece97e60a9fb54c05d6fcf76fc5ca-image.png)

<br />

Fields:

Merchant: This option allows you to select the affiliate or affiliates that will be taken into account when executing the closing.

Forse Batch: Allows you to determine if the closure will be forced.

Cancel: Allows you to suspend the action.

Ok: Allows you to confirm the execution.

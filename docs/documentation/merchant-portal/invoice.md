In this option we can search for the created invoices and filter by the different search fields:

![](https://files.readme.io/407bd7ed25abd12e79c326dcfb94b6777a4ba34e7de6a703b71240db24b6180e-159e785332f93c0e6c4fa91a11d5c9be1adcb7f968924c932abb164649259c9b-image.png)

<br />

Date From: start of the date range.

Date To: end of the date range.

Status: status of the invoice.

Customer Account: Customer identification number.

Invoice Number: Payment invoice number.

Amount From: start of the amount range.

Amount To: end of the amount range.

Once you have selected the filters you want to search for, click the 'Search' button to filter and then view the results:

![](https://files.readme.io/65ac7ff4b5571d866e7b0888f7f7c8073ce904ed0a35fd89a5e1f8e9b0aa9881-aa3950b87a60af64fb59d429ec67c9a4ba36a83277e20f8ffbb966a9194c7d5c-image.png)

<br />

The data table displays the following columns:

ID : Invoice identification number.

# Invoice: Payment invoice number.

Date: Invoice creation date.

Customers: Client name.

Payment Method: type of product used to pay the invoice.

Original Amount: Transaction amount.

Payd Amount: Amount of the transaction.

Status: Status of the transaction.

Actions: Actions that can be performed on the transaction, these actions depend on the status of the transaction:

![](https://files.readme.io/a03ea0cb8276aacb80487358ed048bee2a62e05827b8f906a83401bf7760e003-1dc96653416d84e8a8ae4ad32177387d77d29e53b6b5f0b8187a6ee067056c42-image.png)

<br />

View: Allows you to go to the invoice details page.

Edit: Allows you to edit the invoice.

Send Invoice: Allows you to resend the invoice via email or SMS.

Copy Link: Allows you to copy the invoice link to the clipboard.

Duplicate: Allows you to duplicate the invoice.

Cancel: Allows you to cancel the invoice.

We can also

Add Invoice : Allows you to create an invoice.

Import invoices from a CSV file by clicking the 'Import Invoices' button.

Export the information on the screen to an Excel sheet by clicking the 'Export Excel'  button.

To clear the search fields, we can press the 'Clear' button.

In the ID column we have a link that allows us to see the detailed invoice:

The objective of this section is to explain the integration protocols for the payment process from the merchant site on the Internet (Merchant Website) to the payment gateway using Direct API communications.

It includes in detail, the data that will be sent from the merchant's portal to the Payment System API, as well as the information that will be returned to the merchant's portal so that it generates the payment receipt or invoice of the purchase.

The Web Services Module consists of web services accessible via HTTP / HTTPS, which can be used by external channels or systems to perform operations on the System on the Gateway server.

Web Services can be accessed through standard protocols, such as REST.

Endpoint authentication uses OAUTH 2.0 standard.

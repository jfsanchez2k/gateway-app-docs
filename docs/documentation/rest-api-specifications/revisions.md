| Revision | Date | Description |
|----------|------|-------------|
| 1 | Jun 2012 | Initial version |
| 2 | Sep 2012 | Settings and missing methods |
| 3 | Sep 2019 | Recurring Payments |
| 4 | Jan 2020 | ACH `AccountType` added to response |
| 5 | Feb 2020 | Recurring Payment adjustments |
| 6–10 | 2020 | Name adjustments, VoidSale, recurring payment methods and hash parameters |
| 11 | Jun 2020 | Authorize integrates RegisterToken and AuthorizeToken |
| 12–15 | 2020 | Recurring API URL corrections, EffectiveDate for ACH, AccountType=3 (Savings), CaptureAdjustmentByID, token status |
| 16 | Jul 2020 | **OAuth 2.0** authentication standard implemented |
| 17–19 | 2020–2021 | Recurring /Add adjustments, URI name fixes, VoidSale corrections |
| 20 | Nov 2021 | Recurring endpoints updated for OAuth |
| 21 | Dec 2021 | **RefundByID**, **GetTransactionByReference** introduced; AVS support on RegisterToken and Authorize |
| 22 | Mar 2022 | **Installments Payments** for Visanet; ACH response codes |
| 23 | Mar 2022 | **GetBalance** operation added |
| 24 | Jun 2022 | Amount and Currency fields added to GetTransactionById and GetTransactionByReference |
| 25 | Oct 2022 | Bill Payments and Top Up Operations section |
| 26 | Nov 2022 | **ApplyCredit** and **ApplyCreditToken** methods (ACH push payments) |
| 27 | Jun 2023 | Version reference changed to **/v6** |

Agiltech Gateway is a secure omnichannel Payment Gateway service focused on offering a reusable solution for all customer service and attention channels, to allow the processing of payments with credit cards or ACH accounts of the entire Organization.

***

This payment platform can be integrated into the services through the internet, the services offered through IVR, such as those offered through the Institution's Call Center. Each channel is identified as an affiliate and a terminal of the Institution through which it is identified with the Service.

All channels interact easily with the Platform, and it is in charge of making the connection with the financial processors of the acquirers in the formats and protocols required by them; considering all the conditions of error and reverse of transactions. Additionally, the System handles all financial transactions and closings required by each of the acquirers.

AgilTech Gateway® provides the options to achieve effective control of authorized users, the definition of affiliates, the acquirers related to each affiliate, and other parameters related to their function. This solution is supported by a robust systems platform and a security subsystem adapted to the highest demands of financial institutions and services in relation to Security.

***

The main modules available on Agiltech Gateway are:

- Merchant Portal
- Payments REST APIs
- Tokenization APIs
- Payment Links APIs (Pay2Link)
- Recurrent Payments APIs
- Hosted page payments
- Webhooks APIs
- Point of Sale Integration
- Automatic file exports

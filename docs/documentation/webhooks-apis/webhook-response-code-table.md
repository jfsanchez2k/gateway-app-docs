# Response Codes

Below is a list of the response codes managed by the Payment System.

## Response Codes Description

| **No.** | **Description**                    |
| ------- | ---------------------------------- |
| **00**  | Approved or completed successfully |
| **01**  | Customer not found                 |
| **02**  | Security restriction               |
| **03**  | Payment Not allowed                |
| **91**  | System not available               |
| **96**  | System malfunction                 |
